# web

The web client for the Virtual Arcade: the landing page, and later the 3D arcade shell that hosts games.

> **Status:** Early development. Part of a learning project that simulates enterprise development practices: infrastructure as code, CI/CD with security scanning, and OpenID Connect authentication.

## Repository layout

| Path | Contents |
|---|---|
| `src/` | Application source |
| `infra/` | Terraform for this repository's own Azure resources |
| `.github/` | Workflows, pull request template, code owners |

## Contributing

All changes go through pull requests to `main`. Pull requests must pass all required checks before merging.
